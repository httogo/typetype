# 打字练习网页 App 实现方案

## 需求总结

- **练习内容**: 英文单词和句子
- **核心功能**: 自定义文本输入 + 基础打字统计
- **数据存储**: 纯前端 localStorage，架构上预留后端扩展
- **UI 风格**: 现代简约风（明亮主题、导航栏、卡片布局）

## 技术选型

| 层面 | 选择 | 理由 |
|------|------|------|
| 框架 | React 18 + TypeScript | 生态丰富，组件化开发，类型安全 |
| 构建工具 | Vite | 启动快，HMR 优秀，配置简单 |
| 样式 | Tailwind CSS | 快速实现现代简约 UI，响应式友好 |
| 状态管理 | React Context + useReducer | 轻量够用，无需引入额外依赖 |
| 数据持久化 | localStorage（封装为 service 层） | 前端优先，service 接口便于后续替换为 API 调用 |
| 路由 | React Router v6 | 多页面导航 |

## 功能模块设计

### 1. 打字练习核心

- 文本逐字符对比，实时高亮正确/错误字符
- 当前光标位置指示
- 实时显示 WPM（每分钟单词数）和准确率
- 练习完成后展示结果摘要（用时、WPM、准确率、错误字符分布）

### 2. 文本来源

- **预设文本库**: 内置若干分级（简单/中等/困难）的英文段落
- **自定义文本**: 用户可粘贴或输入自己的文本进行练习

### 3. 练习模式

- **限时模式**: 15s / 30s / 60s / 120s 可选
- **全文模式**: 完成整段文本后结束

### 4. 历史记录

- 每次练习结束自动保存成绩到 localStorage
- 历史记录列表页：展示每次练习的时间、模式、WPM、准确率
- 简单的趋势折线图（可选，使用轻量库如 recharts）

### 5. 设置

- 字体大小调节
- 是否显示实时统计
- 主题切换（明/暗，可选）

## 页面结构

```
/                 -> 首页（快速开始练习）
/practice         -> 打字练习页面
/custom           -> 自定义文本输入页
/history          -> 历史记录页
/settings         -> 设置页
```

## 项目目录结构

```
src/
  components/       # 通用 UI 组件（Button, Card, NavBar 等）
  pages/            # 页面组件
  hooks/            # 自定义 hooks（useTypingEngine, useTimer 等）
  context/          # React Context（AppContext, SettingsContext）
  services/         # 数据持久化 service（localStorage 封装）
  data/             # 预设文本数据
  types/            # TypeScript 类型定义
  utils/            # 工具函数（WPM 计算、准确率计算等）
  App.tsx
  main.tsx
```

## 实现任务分解

### Task 1: 项目初始化与基础架构
- 使用 Vite 创建 React + TypeScript 项目
- 配置 Tailwind CSS
- 搭建路由、布局组件、导航栏

### Task 2: 打字引擎核心逻辑
- 实现 `useTypingEngine` hook：字符对比、光标追踪、状态管理
- 实现 `useTimer` hook：计时器逻辑
- WPM 和准确率的实时计算工具函数

### Task 3: 练习页面 UI
- 文本展示区域（高亮正确/错误/未输入字符）
- 实时统计面板（WPM、准确率、用时）
- 练习完成结果弹窗/卡片
- 模式选择（限时/全文）

### Task 4: 文本来源与自定义文本
- 预设文本数据（内置 3 个难度等级，每级 5-10 段文本）
- 自定义文本输入页面（textarea + 开始练习按钮）

### Task 5: 历史记录与数据持久化
- localStorage service 层封装
- 历史记录页面展示
- 成绩趋势图（可选）

### Task 6: 设置与收尾
- 设置页面（字体大小、统计显示开关）
- 响应式适配
- 整体 UI 打磨

## 关键交互细节

- 用户进入练习页面后，第一次按键即开始计时（无需点击"开始"按钮）
- 输入错误时字符标红，但不阻止继续输入（允许跳过错误字符继续打）
- 支持 Backspace 删除修正
- Esc 键可随时中止练习
- 练习结束后自动保存记录并展示结果
